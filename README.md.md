# Aresys Dundies — First Edition

Sito ufficiale della prima edizione degli Aresys Dundies.

## Funzionalità

- 🏆 Home page in stile Oscar
- 📅 Sondaggio pubblico per la scelta della data
- 🔒 Area organizzatori protetta da password
- 📊 Gestione partecipanti e awards via Excel
- 🎬 Scaletta (in arrivo)

## Come caricare su GitHub Pages

1. Crea un repository pubblico su GitHub
2. Carica tutti i file in questo repository
3. Vai su **Settings → Pages**
4. Source: **Deploy from a branch** → `main` → `/ (root)`
5. Salva e attendi 1-2 minuti

## Password organizzatori

Di default: `aresys2025`
Per cambiarla, apri `script.js` e modifica la costante `ORGANIZER_PASSWORD`.
